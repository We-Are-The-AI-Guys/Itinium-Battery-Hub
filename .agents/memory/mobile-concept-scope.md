---
name: Mobile concept scope
description: Mobile portal exploration must remain separate from the working portal until explicitly approved for implementation.
---
Keep the mobile portal work as isolated, interactive concepts with fictional data until the user explicitly asks to implement it. Admin concepts should match the customer and collector direction rather than introduce a different design.

**Why:** On 2026-10-12 the user requested a concept of how the portal would look and work on mobile before building anything, then approved extending the same direction to Admin.

**How to apply:** Do not interpret concept approval as permission to change production screens, call live APIs, send notifications or publish. Carry existing role permissions and decision consequences into the prototypes.
